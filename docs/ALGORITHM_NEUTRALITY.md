# Algorithm Neutrality

## Purpose

Algorithm Neutrality defines what Market Pulse AI scoring and ranking systems may consider and what they must ignore.

## Principle

Rankings must be based on declared evidence and declared methodology only.

Thai summary: การจัดอันดับต้องอ้างอิงหลักฐานและวิธีคำนวณที่ประกาศไว้ ไม่ใช่ความนิยม โฆษณา หรือผลประโยชน์ทางการค้า

## Implementation Rule

Each active algorithm must publish:

- Evidence it considers.
- Evidence it does not consider.
- Ranking inputs.
- Ranking exclusions.
- Methodology assumptions.
- Known limitations.
- Version identifiers.

## Prohibited Behavior

Rankings must not be influenced by:

- Advertising.
- Sponsorship.
- Affiliate relationships.
- Broker relationships.
- Asset issuer payments.
- User click-through rate.
- Page popularity.
- Watchlist popularity.
- Social engagement.
- Developer preference.
- Founder preference.
- Provider promotional placement.

## User-Facing Disclosure

The UI should explain that rankings are generated by the declared model and available evidence. It must not imply hidden editorial selection.

## Validation Requirement

Automated validation must block activation when commercial, engagement, popularity, or editorial influence is active.

## Known Limitation

The current neutrality contract validates the Penny ranking order exactly. If future engines use different tie-breakers, their expected ranking policy must be declared separately.

## Future Governance Requirement

Any new monetization, sponsored content, or personalization feature must prove it cannot affect algorithmic rank unless it is clearly separated and disclosed.
