# Financial Formula Registry

Financial formulas live in the backend registry, not only in frontend code.

## Current Metrics

Gross margin, operating margin, net margin, ROE, ROA, current ratio, debt to equity, debt to assets, cash to debt, free cash flow margin, cash conversion, P/E, and P/BV.

## Governance

Each formula declares required inputs, domain, role, limitations, and formula text. Formula changes require a version update and test coverage.
