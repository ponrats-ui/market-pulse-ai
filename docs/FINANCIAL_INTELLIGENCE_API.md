# Financial Intelligence API

## Endpoints

- `GET /api/intelligence/assets/{symbol}/classification`
- `GET /api/intelligence/financial/methodology`
- `GET /api/intelligence/financial/{symbol}`
- `GET /api/financials/{symbol}` includes `financial_intelligence` for backward compatibility.

## Contract

Reports expose score, confidence, completeness, primary evidence domain, profile, facts, missing evidence, risk signals, explanations, cache metadata, and version identifiers.
