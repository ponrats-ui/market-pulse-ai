# Financial Intelligence Engine

The Financial Intelligence Engine creates a reusable report for corporate assets using structured provider evidence.

## Report

The report includes classification, profile, score, confidence, completeness, domain subscores, risk signals, facts, missing evidence, evidence metadata, explanations, limitations, and version metadata.

## Non-Claims

The engine does not predict returns, guarantee investment success, detect fraud conclusively, or replace official filings and investor judgment.

## Missing Data

Missing values remain unavailable. The engine does not substitute zero, infer unavailable statement values, or create prose from fabricated calculations.
