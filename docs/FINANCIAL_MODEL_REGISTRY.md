# Financial Model Registry

RC4 introduces profile-specific financial model routing.

## Models

- General Operating Company
- Financial Institution boundary
- Insurance boundary
- REIT / Property Trust boundary
- Unsupported or Unknown Corporate Profile

## Boundary Rule

Banks, insurers, and REITs require sector-specific models. If sufficient sector-specific evidence is unavailable, the system marks the model partial or unsupported and keeps confidence/completeness visible.
