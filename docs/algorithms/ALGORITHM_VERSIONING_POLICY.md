# Algorithm Versioning Policy

Every enabled algorithm must expose methodology, score, policy, and configuration versions.

## Version Meaning

- Methodology version: conceptual model and factor family changes.
- Score version: score formula or contribution calculation changes.
- Policy version: thresholds, eligibility, risk policy changes.
- Config version: operational configuration and scheduler metadata changes.

## Required Updates

Version changes require updated tests, documentation, and change-impact notes.
